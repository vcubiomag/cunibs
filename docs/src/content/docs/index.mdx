cuNIBS computes the electric field induced by transcranial magnetic stimulation (TMS) in an individual head model. It solves the finite-element problem on an NVIDIA GPU and reuses the solver setup across coil placements. This supports placement comparisons, cohort studies, conductivity uncertainty analysis, and searches for placements that maximize the field at a cortical target.
